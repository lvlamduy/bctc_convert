## Original-source admission

The final family-local unit guard runs on both ordinary and PRIMARY projection
paths after source refs are restored, before the printed-total binder and
final local-lane permission. It reads the original caller page JSON and original
query regions, not unit-injected or period-projected clones. It checks every
selected original MONEY table, every active mapping input, every equation
component/result input and every acceptance table receipt. A non-mapping
control table therefore cannot contribute arithmetic under an unknown unit.
Zero-valued source rows do not waive source-unit ownership.

The guard accepts an exact original table unit or uniform original MONEY-column
unit as resolved by the existing pinned unit parser without document context.
Unknown or conflicting local surfaces do not inherit a unit. Every mapping
and table receipt's accepted canonical unit must agree with its original
source proof, and conflicting units within one accepted financial population
hold. No unit is inferred from magnitude, numbers, periods, PRIMARY consensus,
sibling consensus or a bank/file/ordinal rule.

Two existing independently scoped contexts remain narrowly supported:

- An explicit raw continued table has both original reciprocal markers, the
  same document/source and content kind/statement type, immediate physical and
  selected-page adjacency, raw last/first table positions, a source-owned F25
  sender and no conflicting receiver owner. Original MONEY headers must repeat
  exactly, or the receiver headers must be genuinely blank with a complete
  sender axis. The unit carrier must itself be source-owned. A synthesized
  sender marker or copied header cannot grant this permission.
- The existing opt-in numbered-subsection policy is replayed only for an
  immediately adjacent same-page FINANCIAL_NOTE table beneath a printed strict
  dotted descendant of an explicit F25 owner. The parent owns its original unit;
  original period axes must both be complete and agree as a consistency veto.
  A reset, intervening raw table, unrelated outline, PRIMARY carrier, explicit
  unit override or unknown local token cannot acquire this context.
  Nonempty receiver owner surfaces must match exact declared F25 aliases
  (with only the finite “chi tiết” source prefix allowed); a prefixed unrelated
  owner or qualified subsidiary label cannot inherit from numbering alone.

The outline parser is imported from the already pinned frozen evaluator;
there is no new cross-family dependency. These contexts use printed source
structure, never source-value equality. No new PDF/header registry or generic
note-wide/report-wide context is activated. Such a new permission would need
its own actual human-reviewed source context and explicit review.

## Typed HOLD and evidence boundary

On a unit failure the whole candidate is UNRESOLVED with zero mappings and a
specific `ISSUED_PAPER_ORIGINAL_SOURCE_UNIT_NOT_PROVEN:` reason. Its exact
previous candidate, including all mappings, equations, closure permissions,
source refs, unit decisions, values, raw signs, types and prior diagnostics,
is preserved as canonical UTF-8 JSON text with actual SHA-256 and byte size.
The separate withheld-mapping image is null if mappings were already empty;
no nonempty image is fabricated from unrelated evidence.

Unowned financial equations/root grants leave the active closure and remain
in that lossless inactive beforeimage. The active structural receipt has
emitted_mapping=false and cites the unit HOLD receipt. Later numeric/root/lane
finalizers cannot rescue the candidate. The adapter's normal receipt/candidate
identity algorithms reseal the result. Generic recursive mapping audits see
active mappings, not nested beforeimage dictionaries. Fresh public source
replay rebuilds the unit proof and rejects coherently resealed false receipts.

When all consumed source units are owned, the guard changes no mapping,
equation, role, unit, coefficient, sign, source reference or existing financial
disposition. It records source-unit evidence only. The prior LPB printed-root
and SHB transpose permissions still require their own independent source and
financial proofs. MSB/VAB's current-only lane HOLDs remain independent.
