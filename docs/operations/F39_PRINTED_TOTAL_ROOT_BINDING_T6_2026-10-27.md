The PRIMARY adapter previously relied on the frozen engine's direct-frontier
ROOT selection. A current-tax line can have the same amounts as a separately
printed tax-expense total. That equality does not establish which row owns
ROOT. T6 binds ROOT to the unique registered printed total label in the selected
authenticated income-statement table, before note/supplement merging and
signed-display receipts. CURRENT_TAX_PARENT and DEFERRED_TAX_NET are preserved.

The binding rechecks the original page/table hashes, two selected money columns,
canonical unit or the existing query-replayed document-unit corroboration,
component source identities and same printed population ancestry. An intervening
GROUP blocks borrowing across a flattened hierarchy. The total mapping retains
the actual source row ordinal, label, hierarchy, row kind, raw selected values and
source locator. Only directly observed integer or dash-zero source cells qualify;
blank or conditional punctuation/colon cells cannot fall back to current-tax
amounts. The receipt records both the replaced ROOT and its source-owned replacement.

`ALGORITHM_PRINTED_PRIMARY_ROOT_SOURCE_OWNERSHIP_UNPROVEN`, authenticated evidence
and no mappings. Both note and supplemental merges propagate this HOLD. A table
without a registered printed total acquires no new printed-total permission: its
existing private-spec/frontier result and final source controls remain required.
