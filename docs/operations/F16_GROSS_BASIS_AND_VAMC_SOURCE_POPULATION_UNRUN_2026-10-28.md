## Source change

The F16 schema binding now pins that exact basis/population policy. The compiler
rejects a caller changing it to NET, omitting it or changing the VAMC/subset
boundary. The family root remains structural context only.

`_child_records` follows only declared additive children. A guaranteed-debt
NONADDITIVE role remains a separate source view even if Gemini omitted its
“Trong đó” marker or ancestor. VAMC face/provision is no longer appended to
core HTM debt/provision. Equation components cannot reuse one original
VID/section/table/row occurrence in separate slots, including zero-valued
occurrences; those variants cannot close.

Source-owned HTM/VAMC provision summaries are retained as controls, not as
core849 mappings. A broad HTM parent is separated only when an actual later
VAMC child in the same table names that exact printed parent in its hierarchy.
An explicitly printed ex-VAMC provision stays core. Equal amounts do not join
the rows. A generic same-table HTM provision with VAMC but without this child
ownership or an exact ex-VAMC qualifier holds. The new control is checked only
against its fixed raw core-HTM/VAMC provision occurrences, never the global
collapsed role records or an all-family amount search. The printed parent
label must identify one raw occurrence in its table and be the nearest exact
ancestor for each child. A printed reset or next unowned row ends that block;
repeated parents, duplicate equal-valued children and missing/incomplete local
children hold. The frontier contains one directly observed VAMC provision and,
when printed, one explicitly ex-VAMC core provision; other core detail must
belong to that explicit core parent. Unsupported extra source rows hold.

The population receipt binds exact occurrence IDs/source refs, raw parent and
frontier beforeimages, money columns, full local period/unit axes, raw table/
page SHA and the source-block boundary. Its sealed ID is retained alongside
the resolution receipt. The local control equation uses only those raw cells
with exact all-lane closure, even if another table's values or same-role global
aggregate would close the amount. No absent core provision is emitted as zero.
An unrelated “không bao
gồm” phrase is not an ex-VAMC bond exclusion.

Printed NET and combined HTM/VAMC totals can close source controls but cannot
become824/848. Printed gross binding requires its own local axes and source
basis: an explicit gross line, an explicit ex-VAMC core line, or a terminal
core subtotal before its own provision. A generic branch header before all
components is not declared gross from position plus numerical agreement; it
can itself be a net carrying header.

Without an admissible printed gross row, a gross projection requires a complete
observed core frontier in one owned table. Each component must have actual
source rows/cells, a resolved local period/unit, consistent raw source refs,
complete coverage of the classified core roles, no provision/VAMC/subset input
and no repeated source occurrence. Missing/partial cells or a cross-table/page
sum do not receive a new continuation permission. The projection sums only
the printed components, never adds provision back or subtracts it. An
unproved total remains HOLD; a present unproved branch total makes the
candidate unresolved with no active mappings. An absent, unproved total can
remain withheld while independently observed components retain their existing
proposal status.

Every emitted824/848 mapping carries `valuation_basis`, core `population`
and its sealed `schema_basis_receipt_id`. The receipt binds the exact schema,
unit, source proof and original total beforeimages; candidate replay rebuilds
it from raw pages. NET/provision/including-VAMC result equations have source
control roles, not active gross-total result permissions. A source total
without its own consumed population control cannot silently disappear.

Beforeimages and withheld records are lossless canonical JSON UTF-8 text
envelopes, with final LF, actual SHA-256 and byte size. They are inactive
evidence, not nested mapping-shaped dictionaries. The held-candidate path
retains them with zero active mappings. Whole-candidate source-observation
contract tests check that audit counts equal the active mapping list; fresh
replay rejects malformed or coherently resealed false basis/envelope evidence.

The family-local document-unit helper now inventories other units without
donating PRIMARY amount-matched units, PRIMARY consensus or unrelated sibling
table consensus. Local table/all-money-column units remain supported. Missing
unit evidence holds; a future note-owned/PDF-context route needs its own
source proof and review. No unit is inferred from magnitude or PRIMARY values.
Existing source signs, values, typed blanks and bounded printed-rounding
controls are preserved.
