# Role A machine-reference contract

Each JSONL record contains the directive's identity, document/bank/report/scope fields; schema and hierarchy fields; raw and normalized values; period, unit, and sign; page/table/row/column IDs and label/value boxes; source text/image hash; primary and independent OCR; table-geometry sources; MongoDB evidence; accounting checks; confidence/status/reason/conflicts; and creator/code/config hashes.

The contract never labels this output as human gold or production truth.
