## Direct-source adapter and no-left-behind boundary

The family adapter keeps note-detail mappings on their direct note rows and
replaces only the Family-38 root with one exact direct primary income-statement
occurrence when available. The query augmentation receipt binds the primary
page/table/row/columns, exact labels and values, unit evidence, source identity,
and selected page-JSON SHA. The evaluator operates on a private projection;
neither the stored page nor the generic query evidence is mutated. Duplicate
or conflicting primary presentations fail closed.

The root invariant holds for every terminal READY document: all 270 have one
root mapping with one source reference and two directly observed non-null
cells. Of these, 269 roots have state
`SOURCE_VISIBLE_PRIMARY_STATEMENT_EXACT_RESULT`; the one source without a
usable primary occurrence retains its directly observed, equation-proven note
root. No generic-derived root is exported.

Strict family-local source routes also cover:

- exact same-document note/root unit corroboration without altering a value;
- exact unique unit inheritance from the immediately preceding primary
  statement only when every monetary header explicitly carries the same
  accepted unit;
- independent display-unit rounding only through the explicit policy and only
  for a scaled source presentation;
- an exact adjacent continuation whose marker, page identity, axis, component
  union, receiver total, and equation are receipt-bound; and
- exact nonterminal unlabeled subtotals omitted privately only after every
  observed lane proves the contiguous component sum.

A true blank never participates in arithmetic and never becomes zero. A
partially observed mapping retains `coefficient=null` and
`BLANK_SOURCE_CELL`; an all-blank role is omitted. A printed dash remains a
source-observed zero.

The full271 source-only inventory contains 145 rows. Exactly 144 are explicit
subtotals or duplicate declared-role rows consumed by authenticated exact
equations/aggregations. The remaining row is the non-monetary structural label
`Phân bổ cho:`. There are zero `unmapped_direct_family_rows`, so no visible
schema-mappable Family-38 money row is silently discarded.
